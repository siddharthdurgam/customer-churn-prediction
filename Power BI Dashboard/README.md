# 📊 Power BI Dashboard

This project uses Power BI as the business-facing analytics layer for customer churn analysis and prediction.

## Dashboard Pages

### 1. Churn Analysis — Summary

The summary dashboard focuses on:

- Total customers
- New joiners
- Total churn
- Overall churn rate
- Churn by gender
- Churn by age group
- Churn by tenure
- Churn by payment method
- Churn by contract
- Geographic churn-rate analysis
- Service-level churn analysis

### 2. Churn Analysis — Prediction

The prediction dashboard focuses on:

- Predicted churner profile
- Predicted customers at risk
- Customer-level prediction output
- Monthly charge
- Total revenue
- Total refunds
- Number of referrals

## Business Use Case

The dashboard is designed to help business and customer-retention teams identify high-risk customer segments and prioritize retention actions.

## Source

The editable `.pbix` report is not included in the public repository at this stage. The repository keeps the Python/ML workflow and dashboard documentation separate from customer data and machine-specific files.
